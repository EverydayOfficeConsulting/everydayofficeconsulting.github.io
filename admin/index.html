Adding another tool later

Notes for whoever builds it
  1. Give the tool its own folder (like roadmap/) with an index.html for visitors and an admin.html built on platform/admin-common.js.
  2. Put its database setup in setup/<tool>.sql, written so it's safe to run more than once.
  3. Add one entry to platform/tools.js, listing the tables that hold its content.

That's all. It then shows up on the tools page, in this dropdown, in this overview, and in the complete backup and rebuild guide automatically.
